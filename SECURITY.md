# Security and privacy

Do not add any of the following to this repository:

- real names, email addresses, phone numbers, resumes, or application history;
- real employer names, job-posting URLs, platform identifiers, or screenshots;
- cookies, session data, browser profiles, passwords, OTPs, API keys, or `.env` files;
- raw logs or snapshots copied from a production or personal account.
- raw user objections, model transcripts, or Loop Engineer incidents copied from a private workflow.

Use the fake values in `examples/` and `demo/index.html` when demonstrating the project. If a local experiment produces sensitive output, keep it outside this repository and remove it before committing.
