# 실행 연결과 독립 검토 — 2026-10-20

## 문제와 원인

여러 AI 실행자가 분석·작성·검토·입력을 나누는 개인 자동화에서, 인계 메시지의 전달과 실제 착수가 혼동됐습니다. 사건 기록과 정체 판정 로직은 있었지만 실행 기록을 지속적으로 전달하는 연결이 빠졌습니다. 중앙 조율자가 호출을 누락하면 검증도 시작되지 않았습니다.

## 변경한 구조

외부 수집기가 지정된 실행 기록의 새 구간을 읽고 기존 관리자에 전달하도록 연결했습니다. 별도 검토 큐는 기존 관리자의 SQLite 연결로 통합하고, 이전 저장소의 쓰기를 차단해 관리 상태가 갈라지지 않도록 했습니다. 실행자를 제외한 두 검토자의 배정·인수·결과를 기록합니다. 전달 성공, 도구 실행, 독립 검토 의견, 실제 저장 완료는 서로 다른 상태입니다.

검토 행동이 다시 작업으로 등록되는 문제도 발견했습니다. 명령 문자열에서 검토 여부를 추측하던 방식을 바꾸어, 실제 검토 인수 기록의 시각과 같은 실행자의 관측된 턴 구간을 연결했습니다. 중첩 도구 호출, 잘못 입력한 턴 ID, 명령을 인용한 정상 작업을 회귀 사례로 구분했습니다.

수정 요구는 원작업에 연결된 재작업 요청으로 남깁니다. 중복 요청과 이전 작업의 재사용을 거부하고, 인수 이후 관측된 수정본을 연결해 두 독립 검토가 통과해야 재검토 승인 상태가 됩니다. 원래 실패 기록은 보존합니다. 이는 의미적 정확성이나 브라우저 완료의 자동 보증이 아닙니다.

## 검증 범위와 남은 일

비공개 로컬 런타임의 코드·회귀 검사 및 독립 소스 검토를 수행했습니다. 기존 관리자 통합과 수집기의 상태 갱신·새 기록 수집은 관찰했습니다. 재작업 경로는 격리된 테스트로 검증했습니다. 재귀 수정본의 실제 수집기 적용 후 검증, 종료 후 자동 재시작, 실제 웹 입력에서 재작업과 재검토까지 이어지는 검증은 미완료입니다.

따라서 완전 무인 운영이나 자동 복구 완료를 주장하지 않습니다. 테스트 수와 검토 의견은 해당 범위의 증거이며, 전체 운영 성공을 대신하지 않습니다.

이 문서는 비공개 개인 자동화에서 얻은 설계 경험을 일반화한 기록입니다. 이 저장소가 실행 중인 다중 모델 서비스나 실제 채용 플랫폼 자동화를 제공한다는 뜻이 아닙니다. 실제 세션, 계정, 지원 자료, 실행 로그와 로컬 경로는 공개하지 않습니다. 공개 데모의 실행 기능은 기존 README에 명시된 범위입니다.
